# 運営提案・企画の種一覧（Governance & Event Proposals）

メンバーの個人のつぶやき（`03_commons/members/`）や複数人のセッション（`03_commons/sessions/`）の中から、AI エージェントが「コミュニティの運営改善」や「イベント・勉強会の企画」に繋がりそうな種を拾い上げてリスト化する場所です。
