# AI & Science Community (GDG)

Google Developer Groups (GDG) を母体とした、**「AI と科学の関わり」について議論し、探求するコミュニティ**のナレッジベース兼・自律運営リポジトリです。

このコミュニティでは、運営の属人化を防ぎ、メンバー全員の発言が自然にコミュニティの形を作っていくよう、**AI エージェントが実質的なコミュニティマネージャー（整理・接続・運営推進）** を担います。

---

## 🚀 参加・利用方法（チャットの始め方）

ファイルを直接手動で編集する必要はありません。  
AI コミュニティマネージャーとのチャットを通じて、記録・整理・マッチングを自動で行います。

### 💬 はじめかた（3ステップ）

1. **リポジトリを Antigravity で開く**  
   **Antigravity** で本リポジトリをワークスペースとして開きます。
2. **チャット画面を開く**  
   Antigravity の **チャット欄** を開きます。
3. **プロンプトを貼って送信する**  
   以下の **4つのメニュー** から目的に合うプロンプトをコピー（コードブロック右上の 📋 ボタン）し、チャット欄に貼り付けて送信してください。AI が対話をリードしてくれます。

### 👤 1. 初めて参加する・自己紹介する（1人）
```text
このコミュニティに参加したいです！私にいくつか質問をしながら、私のメンバーファイル（03_commons/members/）を作成して、関心が近そうなテーマや他のメンバーがいれば教えてください。
```

### 💡 2. 個人のアイディア・つぶやき・疑問を壁打ちする（1人）
```text
AIと科学に関して、今思いついたこと・気になっていることを雑談形式で話したいです。私の話を引き出しながら整理して、私の個人ファイル（03_commons/members/）の時系列ログに追記し、関連するテーマ（03_commons/themes/）や運営の仮説に繋げてください。
（今考えていること： ）
```

### 👥 3. 複数人で集まって話した結果を書き込む（複数人・セッション記録）
```text
複数人で集まって話した内容（またはメモ）を共有します。参加メンバーと議論のポイントを整理して、セッション記録（03_commons/sessions/）として保存し、参加者の個人ファイルや関連テーマ（03_commons/themes/）、運営への提案に繋げてください。
---
【参加メンバー】：
【話した内容・メモ】：
```

### ⚖️ 4. コミュニティの運営・目標・AIのスキルや構造について提案する
```text
コミュニティの運営方針（または目標・リポジトリ構造・憲法・AIのスキル）について提案・相談があります。すぐに変更するのではなく、まずその変更による「他の部分への影響」や「副作用」を分析して私に提示してください。
---
【相談・提案したい内容】：
```

## 🏛️ リポジトリの構造（3つのレイヤー）

「コミュニティをどう運営するか（運営目線）」と「コミュニティをどう活用するか（メンバー目線）」を区別しつつ、メンバーの活動が自然に運営へと還元される3層構造になっています。

```text
ai-and-science-gdg-community/
├── README.md                        # 案内板・チャット開始用プロンプト（このファイル）
├── AGENTS.md                        # AIコミュニティマネージャーの基本行動原則
├── .github/
│   ├── CODEOWNERS                   # 憲法・AIスキル層の変更に対する承認ルール
│   └── pull_request_template.md     # 変更時の「副作用・影響範囲レポート」テンプレート
│
├── 01_constitution/                 # 【憲法層】コミュニティの根本原則（変更には副作用審査とPRが必要）
│   ├── charter.md                   # コミュニティ憲章（存在意義・価値観・統治原則）
│   └── gdg-alignment.md             # GDG（Google Developer Groups）母体との関わり方
│
├── .agent/skills/                   # 【AIスキル層】AIエージェントの能力定義（変更には副作用審査とPRが必要）
│   ├── member-onboarding/SKILL.md   # 新規メンバーの迎え入れ・個人ファイル作成スキル
│   ├── thought-and-session-curator/SKILL.md # 個人の時系列アイディア追記・複数人セッション整理スキル
│   └── constitutional-review/SKILL.md # 憲法・スキル・構造変更時の「副作用分析＆PR作成」スキル
│
├── 02_governance/                   # 【運営の広場】コミュニティをどう動かすか（目標の模索・企画・提案）
│   ├── goal-hypotheses.md           # コミュニティ目標の仮説リストと検証状況
│   └── proposals/                   # 日々の対話から生まれたイベント企画案・運営改善案
│       └── _index.md
│
└── 03_commons/                      # 【活動の広場】メンバーがAIと対話して知見を貯める・繋げる場所
    ├── members/                     # 【個人】1人1ファイル（プロフィール＋個人のアイディアを時系列で蓄積）
    │   └── _README.md
    ├── sessions/                    # 【セッション】個人に紐づかない複数人での議論・集まりの記録
    │   └── _README.md
    └── themes/                      # 【テーマ】個人のアイディアやセッションから繋がった「AI×科学」の知識ノート
        └── _index.md
```
