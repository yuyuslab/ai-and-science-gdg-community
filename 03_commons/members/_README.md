# メンバー個人ファイル置き場（`03_commons/members/`）

ここには、コミュニティメンバー **1人につき1つのファイル（`<member_name>.md`）** を作成します。  
個人に紐づくアイディアやつぶやきは、日付ごとに別ファイルを作るのではなく、**その人のファイル内の「アイディア・思考タイムライン」に時系列（新しいものが上）で蓄積**していきます。

---

## ファイル命名規則
- `03_commons/members/<handle_or_name>.md` （例：`yuyuslab.md`, `taro.md`）

## ファイル内の構成フォーマット（AI エージェントが管理）

```markdown
# メンバー名（@handle）

## プロフィール・関心領域
- **バックグラウンド**：
- **関心キーワード**：
- **コミュニティでやってみたいこと**：

---

## アイディア・思考タイムライン

### YYYY-MM-DD: アイディアや話題のタイトル
- チャットで話したアイディア・疑問・気づきの要点
- **関連リンク**：[テーマ名](../themes/xxx.md) / [目標仮説](../../02_governance/goal-hypotheses.md)
```
